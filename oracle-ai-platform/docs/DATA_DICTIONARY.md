# Data dictionary

Generated by `npm run docs` from `shared/fields.ts`. Required fields reject the row when missing; optional fields unlock additional analyses (see each report's capability checklist). Empty values stay empty (null), never zero. Timestamps need a timezone (`Z` or `±hh:mm`); dates use `YYYY-MM-DD`. Lists use `;`. Blank CSV templates: Data & connections → Download template.
